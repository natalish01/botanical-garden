# botanical-garden
A responsive website for **Mist Gardens**, a museum and botanical garden. Built from a Figma design as a homework project using plain HTML and CSS.

Live demo:https://natalish01.github.io/botanical-garden/

## Pages and sections

- Header with logo, navigation and membership button
- Hero section ("A Beautiful Adventure Awaits")
- Discover Yourself With Nature
- News & Updates (featured post plus list of recent posts)
- Footer (sitemap, groups, copyright)

## Layouts

The design has three versions:

| Version | Status |
| ------- | ------ |
| Desktop | Almost done (footer and News & Updates styling in progress) |
| Tablet  | Not started |
| Mobile  | Not started |

## Built with

- HTML5 (semantic elements: `section`, `article`, `time`)
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- [Google Fonts](https://fonts.google.com/): Libre Baskerville and Roboto
